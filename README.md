# PFRU-Net
PFRU-Net: A Progressive Frequency-Spatial Feature Refinement U-Net for Breast Lesions Segmentation in Ultrasound Images

This repository contains the official PyTorch implementation of the PFRU-Net

## 🛠️ Environment Requirements
- Python 3.8
- PyTorch 2.0.0
- CUDA  11.8

## 📂 Dataset
The publicly available datasets used in this study can be found here:
- [BUSI Dataset]( https://www.kaggle.com/datasets/aryashah2k/breast-ultrasound-images-dataset)
- [Dataset B](https://helward.mmu.ac.uk/STAFF/M.Yap/dataset.php)
- [STU](https://github.com/xbhlk/STU-Hospital.git)

## ⚙️ How to Run

### Installation
```bash
pip install -r requirements.txt
```

### Training
